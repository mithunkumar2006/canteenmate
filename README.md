# 🍽️ Canteen Mate

A lightweight front-end web application designed to streamline campus canteen meal selection. Built during first year using pure vanilla web technologies.

---

## 🚀 Key Features

* **Food Menu Listing:** Browse categorized canteen items (breakfast, lunch, snacks, beverages).
* **Multi-Page Flow:** Seamless navigation across the menu, food options, and ordering screens.
* **Pure Web Stack:** Fast loading with clean HTML, CSS, and vanilla JavaScript—zero external build tools or frameworks required.

---

## 🛠️ Tech Stack

* **HTML5:** Page structure, semantic tags, and internal link routing.
* **CSS3:** Responsive layout, colors, typography, and interactive button styles.
* **JavaScript:** Client-side event handling and page navigation.
